Interactive models

Change a condition, run the model, and watch the population respond. Each demo is a small browser model for exploring one mechanism.

These demos run locally in your browser. They are simplified browser models. The research simulations run in Flow.

Can a population track a warming world?

Sixteen additive loci adapt across a latitudinal temperature gradient. Migration moves alleles between neighboring bands. Warming shifts the optimum while mutation keeps variation in the population.

temperature optimummean trait

The curves show the local thermal optimum and the average inherited trait. Strong migration can flatten local differences. Strong selection can help populations follow the gradient.

Does a refuge change the outcome?

A predator consumes exposed prey. A refuge protects part of the prey population and reduces predator access to food. Compare the population paths as refuge size changes.

preypredators

This is a discrete predator and prey model with logistic prey growth, predator conversion, and background death. The refuge lowers predation in proportion to the protected share.

How does drift carve a growing frontier?

Two neutral strains expand from a small founder patch. New edge cells copy a nearby parent. Small neighborhoods make random color sectors that reach the frontier.

strain Astrain B

The grid is a simple Eden growth process. Each empty cell at the frontier gets a chance to fill from an occupied neighbor. The founder colors are neutral, so sector boundaries come from sampling alone.

How do selection and drift change allele frequency?

Twenty Wright-Fisher replicates start at the same allele frequency. Each generation applies genic selection, then samples diploid offspring. Small populations show more drift. Selection can drive a beneficial allele toward fixation.

replicatesmean frequency

This browser model uses a single allele, fixed population size and no mutation or migration. Selection follows a genic fitness recursion; reproduction samples 2N alleles each generation. It is a teaching model. The Flow Wright-Fisher engine and the spatial organism model have separate implementations.
